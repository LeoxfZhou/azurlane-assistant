# 碧蓝航线助手

在本地浏览器中检查指挥猫库存、规划舰队、记录舰船个人剧情与装备仓库。
这是非官方的个人管理工具，不是游戏客户端，也不是自动战斗或完整伤害模拟器。

**当前仓库提供 Mac 版本。** Windows 模拟器扫描、识别及游戏内改名不包含在本次发布中；
Windows 版本以后加入独立目录。Mac 可以导入格式兼容的 Windows 库存文件。

## 能做什么

| 功能 | 主要用途 | 详细说明 |
|---|---|---|
| 指挥猫库存鉴定 | 按初始天赋分 S／A／B／C／备，查看专项用途、保留提示与建议昵称 | [指挥猫指南](docs/COMMANDER_CATS.md) |
| 真实编队推荐 | 配置主线／大世界舰娘、用途和优先级，生成并保存司令／参谋组合与培养步骤 | [配队指南](docs/FLEET_PLANNING.md) |
| 全图鉴顶配 | 按自己的分队查看不受库存限制的参考组合，与库存推荐对照 | [理论与库存的区别](docs/FLEET_PLANNING.md#理论顶配与库存推荐) |
| 培养观测 | 只读核对本地历史天赋、目标和截图证据，不影响初始天赋评级 | [培养观测](docs/COMMANDER_CATS.md#培养观测不是实时扫描) |
| 舰船个人剧情 | 按原名／和谐名、阵营、舰种、满级和剧情状态筛选，记录完成情况 | [剧情与装备](docs/OTHER_FEATURES.md) |
| 装备仓库 | 记录型号、数量、强化、锁定与备注，查看参考评级和已核对研发用途 | [剧情与装备](docs/OTHER_FEATURES.md#装备仓库) |
| 数据交换 | 预览后导入库存或编队；多选导出编队及推荐、指挥猫库存 | [存档与同步](docs/DATA_AND_SYNC.md) |

评级用于辅助判断，不会自动删除游戏中的猫或装备。日常读取本地资料；手动更新才访问对应来源。

## 第一次使用

1. 按下方说明启动，在首页进入所需模块。
2. 指挥猫：在“设置”导入兼容的库存包，先预览，再确认替换。
3. 在“库存鉴定”查看初始天赋评级；无需先配置舰队。
4. 在“库存配队”建立方案，选择实际舰娘、用途与优先级，等待自动保存。
5. 查看推荐及培养步骤。已有推荐不会因普通重开页面而自动换猫；需要时点“重新推荐所有方案”。

当前 Mac 的指挥猫界面以**导入、查看和规划**为主，没有手动逐只新增／修改／删除猫的入口。
不要把历史版本的录入菜单当成当前功能。

## Mac 启动

需要 C++17 编译器（Apple Command Line Tools）、CMake 3.20+、Python 3.10+。
双击 `启动碧蓝航线助手.command`，会增量构建并打开浏览器。
脚本支持系统 CMake 和 CLion 内置 CMake，不需要启动 CLion。

也可以在项目目录执行：

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
./build/azur_lane_gui
ctest --test-dir build --output-on-failure
```

Node.js 为可选测试依赖，用于前端语法与逻辑测试。
关闭服务终端或按 Ctrl+C 停止服务。不要把此开发用本地服务暴露到公网。

## 目录与平台

- 根目录当前是 Mac 实现：`src/`、`web/`、`tools/`、`tests/`。
- `data/` 是运行用参考资料，不是个人库存；“参考资料”不代表已取得公开再分发授权。
- `user_data/` 是个人库存、编队、推荐、观察记录及进度；Git 忽略此目录。
- `cache/`、`build/`、`exports/`、原始输入与旧迁移种子也不上传。
- Windows 以后放在独立 `windows/`，保留模拟器专属实现，不覆盖根目录 Mac 版本。

新用户从空库存和未获取的剧情状态开始。已有本地存档不会因构建而被覆盖。
公开版本不附带第三方头像、原始攻略或证据截图；缺图显示占位图。
可通过程序已有的数据刷新功能获取支持的本地资源，请自行遵守来源网站的使用条件。

## 私人数据同步

程序代码与私人存档必须分开管理。此公开仓库不保存个人数据。
当前仍使用 GUI 的文件导出与校验导入；GitHub 一键上传／下载尚未实现。
更新程序代码不等于同步存档。请勿对正在运行的 `user_data/` 直接执行 Git 覆盖。
跨端约定见 [数据边界](docs/PUBLISHING.md) 和 [Windows 接入提示词](docs/WINDOWS_SETUP.txt)。
