# 指挥猫使用指南

[返回首页](../README.md) · [评分标准](SCORING.md) · [编队指南](FLEET_PLANNING.md)

## 用它解决什么问题

- 看初始天赋是否值得保留，而不是根据某个单一毕业模板判断所有猫。
- 找出猫在混编、潜艇、雷击、航速、防潜或阵营等用途中的价值。
- 针对自己的舰队，查看司令／参谋组合及保留、学习、升级、替换建议。

本工具不会执行游戏内删除或改名。Mac 版不连接模拟器。

## 导入库存

在“库存鉴定 → 导入 Windows 数据”或指挥猫“设置”中选择兼容库存包。
先查看预览，确认后才替换本机库存；不把导入视为逐条追加。
格式不兼容、哈希不符或记录非法时应先处理导出端数据，不要手动伪造版本号。
具体文件见[数据交换](DATA_AND_SYNC.md)。

当前界面没有逐只录入、修改或删除按钮。扫描和事实修正应在你的 Windows 工作流中完成，
再导入 Mac。后端仍有部分历史接口，并不等于界面提供相应操作。

## 看懂一张库存卡片

| 字段 | 含义 |
|---|---|
| 实例编号 | 同种猫可以有多只，编号区分具体实例；跨端关联不能只靠名字 |
| 初始天赋 | 用于评级的原始事实；不是当前洗成后的全部天赋 |
| 初始天赋 S／A／B／C／备 | 当前规则下的保留价值筛选，取已覆盖用途的最佳档位 |
| 极品保留 | 即使当前没有用得上的队伍，也不建议因为闲置而丢弃 |
| 待评 | 资料异常或部分用途未覆盖，不等于差猫 |
| 固定成长 | 不参加随机初始天赋分级；培养按固定路线处理 |
| 建议昵称／实际昵称 | 前者是本机按规则生成的建议，后者是导入的记录；建议不会自动改写实际昵称 |

选择档位筛选后，只改变当前显示，不修改库存。展开“每种用途与逐天赋依据”，
可以看到每条天赋贡献的 X 和 Y。初始评级**不需要你先配置队伍**，也不会因为少配一队而下降。

## 昵称如何理解

昵称通常组合用途前缀、职位表达、定位、天赋档位和防重名序号。
例如“战巡兼伤B1”是一个说明格式的示例：战列／巡洋相关用途、兼、输出方向、B 级、序号 1。

- 战／航／潜／轻／雷／速等描述用途；组合前缀可能同时覆盖主力与先锋。
- 司／参表达职位，兼表达用途或候选位置，不保证技能在两个位置都生效。
- 伤／装／速／辅是定位缩写；以实际显示的用途说明为准。
- S／A／B／C／备来自初始天赋评级，不是当前配队里的伤害等级。
- 末尾数字用于区分同前缀猫，不表示等级或优先级。

生成建议时检查重名与本地屏蔽片段（包括 C4），尽量保留已有合法序号。
这不是游戏完整敏感词库，不能保证游戏一定接受所有建议。

## 培养观测不是实时扫描

如果本地已有兼容的观察记录，可展开查看当前观测天赋、历史目标、完成目标及证据截图。
系统核对实例、猫种、初始事实、目标和证据；目标改变或证据不足时会提示复核。

“成”只会作为符合条件时的毕业昵称建议，不自动改写库存，也不意味着 Mac 刚扫描过游戏。
观察数据与初始天赋分开保存：后天洗得好，不会反过来提升初始天赋档位。
普通库存导入包不携带这些证据截图，缺少记录时不能推断已毕业。
