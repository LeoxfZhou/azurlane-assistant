历史记录：指挥猫重构与 Windows 同步协议

本文件保留历史设计过程，含旧目录、旧版本和旧技能计分说明。
当前使用指南以 COMMANDER_CATS.md、SCORING.md、FLEET_PLANNING.md、DATA_AND_SYNC.md 为准。
特别注意：当前技能覆盖按各项效果累加；编队有独立导入入口；存档直接位于 user_data/。

已实现
1. 初始天赋评级独立于旧培养模板，取已覆盖用途中的最高等级。
2. 混合主力／先锋有效初始天赋可以共同计分；后天获得的天赋不进入评级。
3. S 标记极品保留；固定成长独立显示；扫描结构错误或未覆盖用途不等同淘汰。
4. 库存卡片展示用途与逐天赋权重，建议昵称使用同一评级，不改写导入的原昵称。
5. 不同目标天赋的旧排行不再互相借用 k 值。
6. Windows 导入只接受库存，不再覆盖 Mac 设置。

7. 完整舰娘图鉴与小头像：890名舰娘、999个含改造形态的记录，头像约3MB。
8. 独立主线／大世界编队方案；每方案最多8队，同方案禁止重复舰娘（包括改造前后）。
9. 水面队6个槽位，潜艇队3个槽位，允许留空。水面至少一前一后才配猫。
10. 当前方案内猫实例不重复、同队猫种不同；不同方案可以重复使用。

两类评分必须分开
初始天赋等级：无需填写舰队；在通用、混编、阵营、速刷、生存、防潜与雷击专项中取最佳用途。
只评价初始天赋，不考虑后天洗猫成果和等级，也不因当前没配置某种舰队而降级。
S为极品；两项相适配的关键彩即使因普通天赋不足只有A，也有“极品保留”提示。
固定成长单列。扫描结构异常、未知用途保守提示，不自动删除任何猫。
适用方向昵称中的“兼”描述天赋的可选用途，不保证技能在两个职位均生效。
实际配队：根据舰娘阵营、舰种、槽位、队伍用途计算，可使用其他用途的猫作天赋替补。
等级不影响配队；目标由每只猫的初始天赋与最多6个后续点动态生成。
最多5个成长链，普通等级1—3；仅本阵营指挥天赋可后天学习；固定猫专有天赋不进入随机猫候选。
固定猫使用真实30级路线，不能自由洗点。保留／新增／升级／替换分开显示。

推荐计算边界
这是透明的偏好权重模型，不是已测定出率、伤害模拟或全局数学最优证明。
天赋推荐分＝目标天赋的用途权重×等级×受益舰娘人数／本队人数，再对天赋求和。
火4；一发／王牌／狼3；命运2；魂在雷击用途3、其他1.5；风在速刷4、其他0.5；
林／山／奇迹在生存3、其他1；见敌1；声纳在防潜1.5、其他0.1；
舵手／轮机／防空在生存1.5、其他0.4；观测0.75；雷击在雷击用途1.5、其他1；其余1。
这些单位不同于天赋评级中的X、Y，不应互相比较。
技能模板项：每个适用的稳定排行类别计2×类别覆盖比例，合计最多2分，遵守模板职位和场景。
只把它作为已有技能适配证据；不套用其他天赋路线的k值。条件技能不默认全触发。
同一方案先处理候选较少的队，逐队分配；之后按1—99数字弱优先级（越小越优先）交换已有猫。每次受影响两队的总推荐分损失最多5%，全方案保持初始总分95%以上，绝不牺牲已有队伍覆盖。相同优先级不触发交换。
未模拟舰娘自身技能、具体装备、敌人、精确炮雷航空输出占比；鱼雷装备与导驱暴击限制需结合游戏核对。
“全图鉴顶配”按你的实际分队，在全图鉴中选用完整五天赋目标；不依赖库存，固定猫仍用固定路线。不同队可用同猫种的独立假想实例。

存档与资料
舰娘参考数据：data/azur_lane/fleet_ships/catalog.json，portraits/为小头像，包含来源和哈希。
编队存档：user_data/azur_lane/fleet_plans.json。自动保存，版本1，原子替换与冲突检查。
损坏存档不覆盖；显示错误并保留原文件。普通编辑不需要CLion。
设置页的“检查编队舰娘图鉴与头像”先下载暂存资料并显示差异；确认后才应用。
取消不会更改正式图鉴，应用失败回滚。图鉴更新不触碰个人编队或库存。
Windows导入绝不覆盖此文件、舰队设置、舰船剧情或Stella存档。
input只作为原始资料收件目录，不自动导入。

Windows 导出协议
方式一：一个 ZIP，根目录只放下面两个文件，不带子目录。
方式二：同时选择这两个文件。

commander_cat_inventory.csv
UTF-8，标准 CSV，精确表头：
instance_id,cat_id,nickname,initial_talent_ids
只含初始天赋事实，使用现有稳定 cat_id 和 talent_id，天赋以“ + ”连接。
实例编号唯一；不包含评分、后天洗猫结果、舰队设置或 Mac 编队。

commander_cat_manifest.json
{
  "format_version": 2,
  "rule_version": "embryo-2026-10-06-v2",
  "inventory_sha256": "库存CSV原始字节的SHA256小写十六进制"
}

Windows 必须先对齐实际评分规则和事实格式，再宣告该版本。
禁止只给旧格式补版本号冒充兼容。版本号表示兼容声明，哈希仅检查完整性，
不能证明发送端真的实现了评分算法；跨端仍需要共享测试样例核对。
旧版、缺少清单、哈希不符、重复实例或非法天赋整次拒绝。
先预览，再确认替换；任何失败不得覆盖现有库存。Mac 重新计算派生等级。

2026-10-06 编队快照与导出
旧七类界面和数量设置已停用，原存档保留不删除。
新方案首次载入自动生成推荐；已有推荐只读取，直到手动点击推荐才替换。
快照存放 user_data/azur_lane/fleet_recommendations.json，包含目标、猫实例、时间与规则。
编队配置或已选猫猫种/初始天赋变化，标记“配置已变化，请重新推荐”；其他库存猫和纯昵称变化不标记。
设置中导出 mac-fleet-plans.json：format=game-assistant-fleet-transfer，formatVersion=1。
包含 document、recommendations（含stale状态与usedCats校验依据）、被引用舰娘资料、catalogSha256和两个规则版本。
Windows不得用此文件覆盖库存。先校验ID、天赋和规则，再预览、确认应用编队及推荐；用usedCats匹配现有库存，缺猫/天赋不同则保留快照但标记过期。
Mac配队算法版本 fleets-2026-10-06-v3；天赋评级仍为 embryo-2026-10-06-v2，二者不可混为同一版本。
