# 常见问题

[返回首页](../README.md)

## 必须先配队才有 SABC备吗？

不用。初始评级遍历预设用途，取最高档位。自己的舰队影响配队推荐，不影响初始天赋评级。

## 为什么两条特殊天赋的猫可能比一条的等级低？

看的是用途适配、特殊权重和普通有效点，不只数颜色。展开库存卡片逐项核对；
公式见[评分规则](SCORING.md)。不要用导入的旧昵称代替当前卡片评级。

## 备能直接删吗？暂时不用的极品要不要留？

备是当前已覆盖规则下的淘汰候选，不是自动删除指令。先确认初始事实、专项用途和缺失数据提示。
极品保留不受当前有没有合适队伍影响；固定成长、待评也不能当作备处理。

## “兼”是不是两个位置技能一样？

不是。它概括用途或候选位置，实际技能仍检查司令／参谋条件。配队详情中的覆盖原因更具体。

## 为什么后续优先里没有目标中的某条特殊天赋？

可能已经拥有，应该在“已拥有并保留”中；不需要重复学习。
如果目标中存在、既未拥有又不在学习或升级步骤中，则应核对数据或报告问题，不自行认为已完成。

## 初始天赋不在目标里怎么办？

查看“替换”。五槽满后出现新成长链时才可覆盖；同链升级不能作为新链替换。
初始事实用于评级不变，不表示游戏里这条天赋永远不能被替换。

## 自动战斗水雷魂一定没用吗？

当前模型没有把它当作全自动无用。雷击专项和普通混编中的权重不同，
实际推荐还要检查受益舰种。它不是所有队伍的通用高权重天赋。

## 更新库存后为什么还是原来的配队？

推荐是保存的快照。相关配置或依赖变化会提示复核，但不会静默换猫。
检查后点击“重新推荐所有方案”；只有全部计算成功才替换保存结果。

## 主线和大世界可以用同一只猫吗？

可以跨方案复用，同方案不能重复占用。同一实例跨方案的培养目标需统一；
同优先级冲突时调整编号再推荐。更多见[编队规则](FLEET_PLANNING.md)。

## 我的优先级只是轻微偏好吗？

当前统一入口先按数字优先级分批，可能先占用实例并确定目标，并非纯粹末尾微调。
底层弱交换规则不能代表整个统一流程。详见[优先级说明](FLEET_PLANNING.md#当前优先级的实际行为)。

## 头像不显示，程序是不是坏了？

公开代码未附带第三方图片，缺图显示占位图属于预期行为，不影响计算。
本地已有图片会继续使用；支持的图片资源可通过对应手动刷新入口检查。

## pull 会同步个人库存吗？

不会。个人存档被代码仓库忽略，当前没有 GitHub GUI 同步。
按[文件交换说明](DATA_AND_SYNC.md)导入；不要把整个公开仓库当作完整个人备份。

## 文档写来源 WIKI 就能公开转载吗？

不能。来源标注不是授权。文字、整理表和图片要分别核查许可，当前仍存在待核查内容。
