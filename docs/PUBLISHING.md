# 发布与个人数据边界

公开仓库仅管理程序、测试、说明和经过检查的参考数据。
不要使用 `git add -f` 强行添加存档、原始资料、图片、缓存或备份。
提交前运行 `python3 tools/audit_public_repo.py`；该检查是防误提交，不代替人工审查。

个人同步仓库必须为 Private，不能把公开仓库的另一个目录或分支当作私人空间。
库存与扫描观察默认 Windows 为来源；编队及推荐默认 Mac 为来源。
共同编辑前必须设计版本、冲突及依赖校验，不允许静默覆盖。

建议同步：初始库存、实例编号计数、编队、已保存推荐、必要的观察记录与个人进度。
截图可单独按需备份；设备连接配置、绝对路径、凭据、日志及缓存不进入公共仓库。
不要上传凭据，即使仓库是私有的。未来登录授权使用系统凭据存储。

现有 CSV/JSON 导出格式继续使用；GitHub GUI 同步功能尚未实现。
私人仓库的首次上传、截图范围和同步协议应单独核对，不能把整个 user_data 盲目提交。
