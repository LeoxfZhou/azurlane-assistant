# 评分与推荐规则

[返回首页](../README.md) · [库存卡片](COMMANDER_CATS.md) · [配队操作](FLEET_PLANNING.md)

本文按当前源代码核对。初始规则版本为 `embryo-2026-10-06-v2`，
配队规则版本为 `fleets-2026-10-08-v6-talent-audit`。
**所有权重都是工具的可解释筛选政策，不是天赋出率、真实伤害或毕业概率。**

## 先区分三类数值

| 指标 | 输入 | 用途 |
|---|---|---|
| 初始天赋 SABC备 | 猫种、稀有度、初始天赋；预设用途集合 | 判断保留价值，驱动库存筛选和建议昵称 |
| 实际编队推荐分 | 具体舰娘、场景、用途、职位、可达培养目标 | 为某队选择猫与路线 |
| 旧模板难度／排行值 | 已有培养模板及相同目标的来源排行 | 辅助参考，不决定当前初始天赋档位 |

不要把三者相互换算，也不要把旧版界面中的可行度档位当成当前库存评级。

## 初始天赋分级

在自动输出／生存混编、潜艇、轻航低耗、雷击、航速、防潜、辅助及四阵营变体中逐项评估。
取最佳档位；同档位优先特殊权重 X 较高，再比较有效点 Y。

- X：此用途适用的特殊天赋权重之和。
- Y：此用途的有效点之和，一般为普通成长链权重 × 初始等级；部分特殊天赋也可能计入 Y。
- P：本用途权重至少 1.5 的关键特殊天赋数量；不等于所有特殊天赋的数量。

按 S → A → B → C → 备依次判断，命中高档即停止：

| 档位 | 任一条件成立即可 |
|---|---|
| S | P≥2 且 X≥3 且 Y≥1；或 P≥1 且 X≥1.5 且 Y≥3 |
| A | P≥1 且 X≥2.5；或 X≥1.5 且 Y≥2；或 X≥1 且 Y≥3 |
| B | X≥1 且 Y≥1；或 X≥2；或 Y≥3 |
| C | X>0；或 Y≥1 |
| 备 | 以上均不满足 |

一般解释：S 极品，A 优质，B 普通可用，C 过渡，备为淘汰候选，**不是自动删除结论**。
固定猫单列；非法初始结构为待评。若含未覆盖用途的天赋，会警告不要仅凭档位淘汰；
其中原本落在“备”的改为“待评”。

### 权重举例

- 侵略如火：通常计 X=2。
- 适用的一发入魂／王牌机师／狼群之首：对应用途 X=1.5。
- 既定的命运：混编输出 X=1，混编生存 X=0.5；潜艇用途计 Y=0.75。
- 水雷魂：自动混编可计 Y=1；雷击专项计 X=1.5，并可计入 P。
- 其疾如风：航速专项 X=1.5，但不在关键特殊集合里，不计入 P。
- 对应用途的普通输出成长链常为每级 Y=1；其他链可能为 0.75、0.5，或在该用途不计分。
- 被期待的新星、最佳玩伴不贡献战斗评级；缺少它们不会扣分。

完整权重由库存卡片的逐用途贡献展开显示，代码在
[commander_cat_embryo.cpp](../src/commander_cat_embryo.cpp)。
“特殊／普通”是游戏天赋类型，X／Y 是本工具的评分分组，两者不是一一对应。

### 为什么有两条特殊天赋不一定比一条高

还要看它们是否对同一用途有效、特殊权重、普通有效点和初始等级。
例如同一用途 X=1.5、Y=0 是 C，而 X=1.5、Y=1 是 B；只数彩色数量不够。
这只是公式示例，不代表某只真实库存猫。

S 一律提示极品保留；最佳用途 P≥2 且 X≥3 也提示保留，即使普通点不足使其只达到 A。
此提示不受当前有没有相应队伍影响。

## 实际编队推荐分

对每只猫、每个位置生成可达目标，然后计算：

```text
单条目标天赋分 = 用途权重 × 目标等级 × 受益舰娘数 / 本队已填舰娘数
单猫天赋分 = 所有目标天赋分之和
单猫技能覆盖分 = 各项已满足条件的技能（2 × 受益舰娘数 / 本队已填舰娘数）之和
组合推荐分 = 司令天赋分 + 司令技能覆盖分 + 参谋天赋分 + 参谋技能覆盖分
```

技能按满级口径检查职位、模式、阵营和编队条件；同一技能内受益对象去重，
同一舰娘受到多项技能覆盖时可分别计入。**不是全猫封顶 2 分。**
依赖敌人、距离、血量、弹幕等未建模条件不默认全部触发。

主要天赋用途权重：

| 天赋／成长链 | 权重 |
|---|---|
| 侵略如火 | 4 |
| 一发入魂／王牌机师／狼群之首 | 3 |
| 既定的命运 | 2 |
| 水雷魂 | 雷击专项 3，否则 1.5 |
| 其疾如风 | 速刷 4，否则 0.5 |
| 其徐如林／不动如山／小小的奇迹 | 生存 3，否则 1 |
| 见敌必战 | 1 |
| 声纳 | 防潜 1.5，否则 0.1 |
| 舵手／轮机／防空 | 生存 1.5，否则 0.4 |
| 观测 | 0.75 |
| 雷击成长链 | 雷击专项 1.5，否则 1 |
| 其他 | 通常 1，仍需受益对象匹配 |

不适用的目标即使权重高，也不会凭空获得覆盖分。例如水雷魂的覆盖不扩展到重巡或潜艇。
详见 [commander_cat_fleets.cpp](../src/commander_cat_fleets.cpp) 中的 `affected`、`unit` 与 `fleetSkillValue`。
本模型没有完整模拟舰娘技能、装备、敌人和输出占比，也不保证全局数学最优。

## 旧模板的难度参考和 k 值

旧模板仍可在库存详情中查看，但不用于当前 SABC备筛选：

```text
难度参考分 = max(0, 100 − 后续所需点数 × 8 − 缺失目标天赋附加难度)
```

不可达路线为 0。仅目标中缺失的天赋计附加难度：火 20，一发／王牌／狼 10，
魂／风 3，新星／玩伴 0，其他特殊 6，新普通成长链 3。
未被目标要求的天赋不因“缺少”而扣分。该值不是成功概率。

来源排行的 `k% = (k1 / k2 − 1) × 100%`，k1／k2 是原排行计算量。
本工具没有据此建立完整伤害模拟，不能把它当作天赋出现概率或实际全队增伤。
只有路线与来源目标匹配时才使用相应排行；缺少量化数据时显示未量化，而不是伪造百分比。

旧模板“来源排行相对上限”比较该路线加最强兼容搭档与同类别稳定理论组合的来源排行合计值。
它与当前按实际舰娘计算的推荐分不是同一尺度。

历史模板内部仍保留难度参考档位（85／70／50 分分别为 S／A／B 下限）和
相对上限档位（95／85／70 分分别为 S／A／B 下限），其余为 C。
这些内部档位**不替代库存卡片的初始 SABC备**。
模板最终路线优先可达、可量化且上限高的候选；实用路线优先在上限至少 85 分的可达候选中
避开“不建议洗”、选择难度参考分高的路线。没有该类候选时使用难度分与上限分的加权回退。
所以实用路线是模板参考的过渡方案，不是当前真实舰队的另一套固定标准。
